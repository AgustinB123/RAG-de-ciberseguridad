## 4. Fases de Respuesta (Plan de 5 Pasos)

### Fase 1: Detección y Reporte

- Cualquier empleado que sospeche un incidente (Ej: un correo raro, un programa que pide rescate) debe:
  1. **No hacer clic** ni seguir interactuando.
  2. **Desconectar el equipo de la red** (quitar el cable o apagar el Wi-Fi).
  3. **Reportar inmediatamente** al Coordinador de Incidentes.

### Fase 2: Contención

- El Coordinador evaluará la gravedad.
- Se procederá a aislar los equipos afectados para evitar la propagación (Ej: bloquear el acceso a la red, suspender cuentas comprometidas).
- Si es un correo de phishing, enviar un aviso masivo al resto del personal para que no abran el mismo correo.

### Fase 3: Erradicación y Recuperación

- Eliminar el software malicioso o la amenaza.
- Restaurar los datos afectados utilizando las **Copias de Seguridad (Backups)** verificadas.
- Cambiar las contraseñas de las cuentas afectadas.

### Fase 4: Comunicación

- Si el incidente afecta datos de clientes o es de gravedad, el Coordinador definirá la comunicación oficial a clientes y proveedores.
- Se debe evitar dar detalles técnicos que puedan generar pánico, informando solo el estado del servicio y los pasos a seguir.

### Fase 5: Lecciones Aprendidas

- Una vez resuelto, el equipo directivo se reunirá para analizar qué pasó.
- Se documentará el incidente en un reporte breve.
- Se actualizarán las políticas de seguridad para evitar que vuelva a ocurrir.
